# 原增强器的可移植C参考

这是保留的2,809参数增强器与观测前端的C移植，不改冻结C16检测器，不训练新模型。完整数值证据及R7离线候选见[报告41](../../docs/41_逐源增强C移植与R7离线候选_20261019.md)。

接口在`include/mic16_enhancement.h`：

- `m16_enh_mask`：67×64×10特征→67×64掩码，保留FP16输入往返、FP32网络计算。
- `m16_enh_window`：40960×16归一化PCM＋独立8192×16背景＋完整有效C16方向池＋当前轨迹，逐个输出所有新鲜确认ID。
- 回调中的特征、掩码、复数谱、WDAS／增强波形是借用缓冲；下一源复用。返回非零会使整个窗失败，先前回调只算部分结果，调用方必须丢弃该窗。

动态GCC通道权重、6抽头Lagrange、256/625重采样、512点周期Hann STFT、三层因果残差网络、带掩码ISTFT保持旧Python语义。检测器的线性插值／等权波束不能代替本增强前端。网络参数2,809不包含冻结检测器的29,441参数。

工作区约3MB，静态放DDR／BSS，不能放任务栈；共享的extended工作区只能在检测完成后顺序借用。纯C核不访问设备、不创建线程、不更改输入比例、标定或时间戳。

**当前是逐窗16778点、16kHz输出，不是连续全局采样轴。** 不允许直接把多个窗拼起来冒充连续音频；PC连续输出曾修正的累计长度问题仍须在ARM连续移植中保持。没有HLS／定点等价或ARM实际执行成绩。

数值核验工具集中在部署包`verification/enhancement_c_port_20261019`，注册协议、原权重导出、核心对照、两段原会议室输入对照、候选链接和ELF检查均在该目录。不要重新运行`prepare.py`覆盖注册记录；要重做实验使用独立有界运行记录，不能覆盖既有成功／失败证据。

候选仍使用现有`software/vitis_av2/workspace`、R7 BSP和链接脚本。正式视频ELF、BIT、XSA与Run As默认目标保持原样；候选不自动下载，输入／声像标定／物理时间戳门均未打开。
