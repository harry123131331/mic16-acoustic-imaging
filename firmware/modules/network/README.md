# R7裸机逐源网络候选

原R7平台已提供PS以太网GEM驱动，但不含lwIP。此模块直接编译本机Vitis 2020.2 `lwip211_v1_3`的36个原始源文件，生成候选私有库；使用原R7 BSP、CPU、BD、BIT与XSA，不使用旧FreeRTOS的lwIP库，不改原BSP、不新增workspace。

## 链路

已有3窗采集结束 → 冻结C16有限回放 → M16L当前源方向 → 原逐源增强预测 → 连续重建 → M16S各源WDAS／增强双音轨 → lwIP raw UDP → PC独立逐源接收／完整窗保存 → 界面方向与音频预览 → 已保存音频切换试听。

**仍是有限回放候选，未执行过本候选；不是持续实时采集固件。** 主机环回测试没有使用阵列或摄像头。没有修改定位、增强权重或声学算法。送入lwIP成功只代表软件提交，不代表PC收到或物理硬件通过。

## 现场参数与入口

- [mic16_network_site.h](include/mic16_network_site.h)：默认板卡192.168.1.10，PC192.168.1.100，掩码255.255.255.0，独立UDP5001，包间隔250微秒。本地MAC为02:00:00:16:00:07。必须核对实际网卡；`M16_NETWORK_SITE_VERIFIED=0`，本轮保留关闭。
- 网络与音频输入比例／实体通道、声像标定是不同保护项。不能只改网络开关就绕过未确认的音频输入。
- 当前ARP修正候选在原APP的`Debug/candidates/source_network_20261019/mic16_av_r7_source_network_arp_query.elf`，原`mic16_av_r7_source_network.elf`作为修正前候选保留。正式视频ELF与默认Run As保持。
- 构建与检查在`../../verification/source_network_20261019/`。ARM编译器需可启动，Q:须为原release的ASCII别名；不复制整套工程。源码不修改本机Vitis安装目录。

## 接收和试听的手动操作

1. 通过工程原入口打开精简上位机，数据源选“逐源定位 / 增强 UDP”。旧“板端 UDP”仍是旧5000协议，二者不能混用。
2. 在“连接设置”填本机监听地址、板卡来源IPv4和5001；“无数据超时”可设1—120秒，有限回放默认120秒。原定位显示5秒过期规则保持，不因网络等待变长而保留旧点。
3. 点“接收并保存”，选择保存根目录。每次连接创建新`source_udp_<UUID>`段；全部源的两路音频均保存，选源／选WDAS或神经增强仅改变预览。
   当前候选的有限采集仍按原SOP用UART的R／A触发；界面不会发送旧RTOS“启采”命令来冒充该候选控制。输入保护未核验时，候选停在保护状态，不应期待有UDP音频。
4. 完整段收到最终窗才写COMPLETED。通过“文件→打开逐源增强结果”选择该会话，可逐源切换WDAS与神经增强试听。新网络未传MIC0，界面不制造混合输入；旧PC离线会话仍可听MIC0。
5. “断开”停止接收；未收到最终窗、缺片、ID冲突、CRC错或超时都保留INCOMPLETE。另起新段，不把上一段的匿名ID当成同一说话人。没有边收边听或自动播放。

保存为16kHz Float32 WAV，每个ID各有WDAS／enhanced；元数据记录完整窗和当前确认标志，`directions.jsonl`记录接收方向。无源窗允许0音轨，不伪造MIC0或声源波形。未活动源对齐的零是时间轴占位；不能补运输丢失。半途写盘失败的段不会标为完整，不作为完整录音打开。当前上限每段累计128个ID、960万点（10分钟）；界面缓存、录音数据与绘图缓存分开。

## 协议与故障处理

M16S v1保持[连续模块格式](../continuous_reference/README.md)。M16L v1新增方向清单：头36字节、每源28字节，最多260字节；小端。

|偏移|类型|意义|
|---|---|---|
|0|4字节|ASCII M16L|
|4,6|u16×2|版本1、本周期确认源数0—8|
|8,12|u32×2|epoch、输入窗序号|
|16,24|u64×2|原始音频起点／终点，严格为窗序号×40960及下一窗起点|
|32|u32|CRC32，覆盖前32字节头＋源记录，不含CRC字段|
|36起|u32＋3×float64|源ID、方位角、俯仰角、模型分数；仅当前确认源|

原输入采样率78125/2 Hz；相对音频时间没有标定为摄像头物理时间。方向与音频的epoch／窗序号／当前ID必须对应；三窗上下文中的过渡音频不显示成当前源。方向位置只来自接收清单，不从正弦波或音量生成。

网络初始化先用`etharp_query(..., NULL)`建立待解析条目，最多等待3秒，期间由lwIP定时器处理ARP重试；未解析成功不发送音频首包。已分配pbuf在复制／发送失败时释放；超时／发送失败仍锁存并停止本段，不自动重新接续。不支持TCP、DHCP或DNS。GEM中断负责驱动描述符，主循环轮询协议栈定时器。描述符使用原厂1MiB对齐的不缓存区，离线ELF检查其地址在CPU DDR、未侵占视频DDR。
