# D3E自动PCM全链C参考

相同PCM与独立参考自动生成空间票/C16，再计算130维、冻结评分和跨周期状态。有限数值传播核验通过，方向仍有FP32坐标位差，旧D3B逐位门失败保留。

完整依赖ARM库：`build/libmic16_pipeline_arm.a`。尚未链接/执行完整ARM音频应用、未验证DMA或HLS替换。PS DDR调用者拥有约11.36MB工作区和输出/输入；不使用堆。

完整结果见部署包`docs/13_自动PCM整链C移植核验_20261015.md`，结构和协议学习见文档14。全零数值输入仍被原Python/C接受一个候选，部署时不能把未完成采集的零缓冲当有效PCM。
