# D3第三段：固定候选下的物理88维

输入：归一化PCM[40960,16]、独立参考[8192,16]、FP64方向[C,2]及原始票[480,9]。输出：FP32[C,20,88]，C=1..16。无分类、网络、训练或DMA操作。

两份固定数值输入、32候选对照通过，最大特征差7.45e-8；13项接口检查通过。ARM对象库仅交叉编译，未BSP链接、未实板执行；需D3第一段频谱库、D3第二段球面角函数及BSP／libm／libgcc。

冻结Python为金标准。本段使用相同候选方向，未处理或重新判定D3第二段空间谱到加权方向的严格逐位失败。仍缺16kHz统计18维与竞争24维，尚非完整PCM到评分链。

C参考工作区4,908,480字节，由调用者置于PS DDR；没有堆分配。测试程序的大静态数组不等于实时DMA缓冲实现。结果、协议与绘图小数组在`verification/physical_features/`，完整说明见部署目录文档10。不要覆盖已保存的一次核验结果。
