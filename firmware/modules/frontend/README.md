# D3第一段：频谱与相位C参考

本目录只含归一化PCM到频谱、32对PHAT、24带功率与四帧背景参考，未实现完整130维候选特征，不是可直接采集音频的Vitis应用。

- `include/`、`src/`：调用者持有缓冲区，无堆分配。
- `tests/`：本机数值数据接口与14项检查、7组旧PHAT字解码。
- `build/libmic16_spectral_arm.a`：Cortex-A9 hard-float对象库，尚未BSP链接或ARM运行。
- `../../verification/spectral_front/`：事前协议、误差、逐输入表和ARM编译证据。
- `../../docs/08_PCM前端映射与频谱相位C参考核验_20261015.md`：130维映射、复用边界与后续步骤。

同一窗、同一模型判断的基线仍为冻结Python；该C参考没有修改上位机模型。不要将测试程序中的静态数组作为实时DMA缓冲设计。已完成的一次核验不应反复运行；协议和输入哈希用于审计复现，构建核验脚本会拒绝覆盖已保存结果。
