# 演示视频拍摄脚本

建议总时长150秒，输出MP4、AVC/H.264，3分钟内且小于300 MB。下面是待录制分镜，不使用参考视频或离线回放冒充本作品实测。

| 时间 | 画面 | 讲解 |
|---|---|---|
| 0～15秒 | 作品名称和系统框图 | 16路阵列、Zynq、UDP、Qt、USB摄像头 |
| 15～35秒 | 阵列与开发板实拍 | 说明共享时钟、独立数据线和网线连接 |
| 35～55秒 | 上位机连接和开始 | 板卡已加载待机；如剪辑下载过程，标注剪辑 |
| 55～95秒 | 固定声源与方向页 | 宽带人声或音乐持续播放，观察小点和角度 |
| 95～125秒 | 移动声源与相机叠加 | 同录播放设备和软件，缓慢左右、上下并停留 |
| 125～140秒 | 停止与再次开始 | 等待就绪，显示新运行轮次 |
| 140～150秒 | 总结 | 说明当前版本、测试条件和仍需量测的指标 |

录制前固定阵列和相机，检查声像对齐。避开校徽、导师或队员姓名、电脑用户名等无关信息。物理反应时间需要同一画面可见参照，不能由USB视频帧率推断。
