# MIC16 GUI 使用说明

## 当前默认入口（2026-10-18）

双击工程根目录 **[启动上位机.cmd](../启动上位机.cmd)**，或 **[开始运行.cmd](../开始运行.cmd)** 选9。新版以声源方向图为主，下方保留通道波形/频谱，右侧显示源列表；只保留连接、录制和保存等日常操作。默认未连接，演示需显式选择。操作、数据边界及前后对照见[精简改版说明](../docs/00_project/MIC16_上位机精简改版与对照_20261018.md)。

当前可在“文件→打开逐源增强结果…”查看每源独立连续WAV，切换神经增强、WDAS与混合输入；默认指向本次P0仿真结果。此入口不运行定位或连接板卡，[操作和核验](../release/pc_incremental_c16_frozen_20261015/docs/37_C16逐源连续重建与试听接入_20261019.md)。

**下文是历史 `mic16_gui.py` 的使用记录，不是当前精简Qt入口。** 需要旧七页Qt研究界面时使用`启动上位机.cmd -ResearchUI`。当前R7视频固件没有持续UDP流，不能仅凭新界面已打开就认为实板定位已打通。

## 启动

```powershell
cd "D:\vscode\python_class\python_tools"
python mic16_gui.py
```

比赛专注界面：

```powershell
python mic16_gui.py --demo
```

GUI 默认最大化显示；“实验与导出”页支持垂直滚动，低分辨率显示器也可访问全部标签和按钮。

## 六个工作区

1. **比赛演示**：方向、Top-3、质量、延迟、增强和证据来源的现场主视图。
2. **工程总览**：板卡模式、当前结果、质量状态、日志和快捷任务。
3. **实时采集**：16 通道共享真实 PCM 纵轴；逐通道归一化只用于观察，不能做健康判断。
4. **定位分析**：GCC-PHAT/SRP-PHAT 诊断和正式 PC 模型结果。
5. **实验与导出**：带标签录音、MATLAB R2024a 自动报告、SNR 和论文实验。
6. **系统维护**：回放、校准和运行配置。

比赛页严格区分 `PC 实时参考`、`录音离线回放` 和 `板端实时接口`。未收到真实增强音频时，增强阶段不会点亮。

## 带标签录音

录制信号前必须填写：数据用途、信号类型、声源类型、方位角、距离、session、scene 和 source ID。GUI 在开始前弹出二次确认。

推荐顺序：

```text
CAPTURE
-> 开始监听并检查波形
-> 录制静音参考
-> 填写并确认标签
-> 带标签录制 + 自动报告
-> 打开最新报告/00_结果索引.md
```

录制期间 GUI 会暂停 UDP 监听，让 recorder 独占端口；完成后自动恢复监听。

## 状态解释

- “采集门禁拒绝”：原始录音存在饱和、常量、shape 或连续性问题，仅做故障诊断。
- “MAT 已导出，MATLAB 图未生成”：原始数据和 MAT 已保留，检查 MATLAB.exe 和日志即可重画。
- “录音、MAT 与 MATLAB 图已完成”：完整链路成功，仍需依据数据用途决定能否参与训练或论文指标。

默认 MATLAB 报告根目录：

```text
project/results\matlab\capture_reports
```

每条报告只从同一条录音生成，禁止跨 run 拼接示例数组。

## 后台逐源录音处理（2026-10-19）

菜单“文件→处理16通道录音…”在独立算法进程中完成全源处理和保存；界面只取最新进度。需要39062.5Hz、[-1,1]的Float32 NPY和独立背景，不能直接传raw_i32.npy；不隐式猜缩放。普通查看使用“打开逐源增强结果…”。[操作、验收及首次试听等待](../release/pc_incremental_c16_frozen_20261015/docs/38_连续输入后台处理与逐源保存验收_20261019.md)。

## 整数输入与异步试听（2026-10-19）

“处理16通道录音…”支持显式Float32或经确认格式的int32；后者必须选择匹配的比例/通道/固件证据，当前R7待确认模板拒绝运行，不猜除以2³¹。打开结果时波形先显示，试听设备在独立进程准备，点播放才播放。[核验与操作](../release/pc_incremental_c16_frozen_20261015/docs/39_整数PCM显式接口与异步试听修正_20261019.md)。
